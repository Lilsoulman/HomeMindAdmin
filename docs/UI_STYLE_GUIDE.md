# HomeMind Web UI 风格指南

## 目标

Web 是宽屏家庭管理工作台。界面应优先呈现状态、影响范围和下一步操作，不使用装饰性渐变、漂浮装饰或与任务无关的图像。`src/styles/index.scss` 是设计令牌唯一来源；页面只能使用语义变量和 Element Plus 组件，不在组件中硬编码颜色或间距。

## 设计令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 主操作 | `#4DA3FF` | 选中状态、确定性主操作 |
| 健康/完成 | `#3DD6A0` | 已确认完成、健康状态 |
| 正文 | `#1A1A1A` | 主要内容 |
| 背景 | `#F5F6F8` | 工作区背景 |
| 表面 | `#FFFFFF` | 卡片、表格、表单、弹层 |
| 次级文字 | `#71717A` | 时间、来源和辅助说明 |
| 边框 | `#E4E4E7` | 分隔线和输入描边 |
| 页面内边距 | `24px` | 工作区默认水平/垂直内边距 |
| 表面圆角 | `12px` | 独立信息表面 |
| 控件圆角 | `8px` | 按钮、标签、输入框 |
| 区块/关联间距 | `24px` / `12px` | 主区块与关联控件间距 |

风险和健康使用 `--risk-l1`、`--risk-l2`、`--risk-l3`、`--health-healthy`、`--health-degraded`、`--health-low-battery`、`--health-offline` 语义变量。设备健康只展示语义标签，并标记采样时间；过期数据不得描述为实时。

## 布局与组件

- 固定侧边栏只出现仪表盘、设备管理、场景配置、记忆管理、系统设置五项；账户和退出登录位于侧栏底部，不构成第六个模块。
- 页面按 F 型阅读：标题与上下文 → 状态摘要 → 单一主操作 → 数据表面/审计记录。
- 宽屏优先支持 1024px 以上，最小可用 960px；使用 `el-row`/`el-col` 和弹性布局，不以固定宽度造成横向溢出。
- 使用 `el-card` 承载独立数据表面；批量管理使用 `el-table`；删除、高风险策略变更和撤销必须二次确认。
- 每个异步表面都有 `v-loading`、`el-empty`、错误说明和重试。受控不可用不是空数据：明确说明等待的 Core 契约，不显示演示内容。
- Development 模拟家庭数据必须使用警示表面明确标注“开发期模拟数据”和 Core 免责声明；不得把模拟状态文案写成实时、已执行或已确认。
- 场景确认卡包含标题、影响范围、L1/L2/L3 风险、时间和确认/拒绝入口；已终态仅只读。预演必须显著标记为“预计结果”。
- 可复用的基础交互统一使用公共组件：`PageState` 管理空态/错误重试，`AppDialog` 管理 `v-model` 弹层和 footer slot，`StatusTag` 管理状态到语义色的映射；页面不复制这些实现。

## 模块呈现

| 模块 | 首要表面 | 关键状态 |
| --- | --- | --- |
| 仪表盘 | 家庭状态摘要、自动化健康、最近执行日志 | 来源、更新时间、待确认数量 |
| 设备管理 | HA 连接、空间/设备表格、健康摘要 | 离线、低电量、降级、采样时间 |
| 场景配置 | 模板/实例、生命周期、预演、执行步骤审计 | Draft/Enabled/Learning/Stable/Paused/Archived、部分失败 |
| 记忆管理 | 候选记忆、保留策略、反馈审计 | 候选、已审核、已拒绝、已撤销 |
| 系统设置 | 家庭成员、信任策略、密钥写入、自动化健康 | owner/admin、保存中、冲突、无权 |

凭据、HA 地址、原始实体 ID、Prompt、完整错误和第三方原始载荷不能出现在 UI、复制文本、工具提示或日志中。
