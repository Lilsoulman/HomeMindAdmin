# HomeMind Web 产品与信息架构

## 定位

HomeMind 是会记住家庭习惯、自动优化设备场景的家庭控制中枢。Web 是稳定网络下的深度管理端，负责配置、维护、批量编辑和审计；它与 App 共享家庭、权限、场景、记忆和确认事实，绝不创建独立业务规则或绕过 Core/HA。

App 负责日常语音和一键控制；Web 不提供日常设备遥控或场景一键执行。Web 中的场景操作仅限配置、预演、审计和确认中心的同步处理。

## 固定侧边模块

| 模块 | 目标路由 | 主要职责 | 权限与边界 |
| --- | --- | --- | --- |
| 仪表盘 | `/app/dashboard` | 全屋状态、最近自动化日志、待处理确认摘要 | 只读；状态带来源与更新时间，过期数据不称为实时 |
| 设备管理 | `/app/devices` | HA 连接、发现、已配对实体、空间分组与设备健康 | 仅管理 HA；不直连 Zigbee、MQTT 或厂商云；不展示 HA URL、令牌、原始实体 ID |
| 场景配置 | `/app/scenes` | 模板、家庭实例、生命周期、预演、规则、执行审计与失败步骤重试 | 配置/预演不应伪装为执行；实际执行、确认和撤销均以 Core 返回的运行事实为准 |
| 记忆管理 | `/app/memories` | 个人与家庭候选记忆、批量治理、保留策略和反馈审计 | 不把自动执行直接写成偏好；候选须经过审核和 Trust 边界 |
| 系统设置 | `/app/settings` | 家庭成员、信任策略、密钥写入、自动化健康与系统设置 | 仅 `owner`/`admin` 可写高风险配置；密钥只写入 Vault，界面绝不回显 |

当前路由以 `src/router/routes.js` 为唯一来源。仪表盘和设备管理已接入 Core Development 只读模拟家庭数据；页面始终显示 `IsMock` 免责声明，模拟数据不代表 HA 状态，也不能用于执行、确认或写入。场景、记忆和系统设置在字段级契约核验前继续展示受控不可用状态。

Web 前端基线为 Vue 3 + Element Plus。跨模块一致的状态反馈、弹层和状态标签分别由 `PageState`、`AppDialog` 与 `StatusTag` 公共组件提供，页面仅组合业务内容，不重复实现基础交互。

## 核心流程

1. 用户登录后进入仪表盘，查看全屋状态、自动化健康和待确认事项。
2. 管理员在设备管理中完成 HA 连接、发现、已配对实体和空间分组的配置。
3. 管理员在场景配置中查看模板与家庭实例，预演影响，调整生命周期或规则，并审计真实执行结果。
4. 用户在记忆管理中审查候选、保留策略和反馈；系统不以自动动作为个人偏好。
5. `owner`/`admin` 在系统设置中维护家庭、信任策略、自动化健康与密钥写入；所有写操作以服务端 `403` 为最终判断。

## 安全与状态边界

- `homeId` 只能由令牌中的家庭边界确定，不能由 URL、表单或缓存覆盖。
- 页面必须具备 loading、empty、error、retry 与无权状态；写操作禁止重复提交，需要幂等键时一次用户意图复用一个 UUID。
- 运行/确认流保存 `runId` 并轮询至终态；真实结果区分成功、部分成功、失败、取消和超时，失败步骤才可重试。
- 不展示或缓存凭据、Prompt、模型思考过程、设备原始实体 ID、HA URL、原始第三方载荷或完整错误响应。
- 401 只触发一次会话刷新；403 显示无权；404 按不可见资源处理；409 刷新资源后提示冲突；422 显示校验信息；5xx 只提供安全重试。

## 已下线范围

财务、缴费、快递、宠物、日程、出游、待办、专家/Skill、会话、媒体/剪辑、思维导图、小红书与旧微信/IM 授权不属于 HomeMind 当前产品范围。它们不得出现在 Web 导航、路由、页面职责、API 接入文档或新代码中。
